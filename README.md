# СР-2 — аудит успадкованого коду LibraryDesk

- Варіант: 2 — `LibraryDesk`.
- Модуль-донор: `LoanManager.Issue`.
- Розрахунковий вузол: строк видачі та пеня за прострочення.
- Джерело: Б, адаптований навчальний зріз власного проєкту `LibraryDesk`.

> Відхилення від методичних вимог: код походить із поточного семестрового
> проєкту, а не з іншої дисципліни. Використання такого джерела потребує
> письмового погодження викладача. Репозиторій не видає цей код за пакет,
> отриманий від викладача.

## Запуск

```bash
dotnet run --project src/LibraryDesk.Legacy.csproj
```

Після створення страхувальної сітки:

```bash
dotnet test
```
